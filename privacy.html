Syncro Privacy Policy

Last updated: 2026-11-16

What Syncro accesses

Syncro uses the Google Drive scope drive.file. It can only see and manage files it created itself in the user's Google Drive. It cannot read any other files in the account.

How data is used

Syncro uploads files from folders the user selects on their own computer to their own Google Drive. All processing happens locally on the user's computer.

Data storage and sharing

Syncro has no servers. The developer does not collect, store, transmit, sell or share any user data. The Google sign-in token is stored only on the user's computer and can be revoked at any time from the Google Account security settings.

Contact

Questions can be opened as an issue at github.com/acidburn11/syncro-site.
